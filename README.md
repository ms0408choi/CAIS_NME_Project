# Review Balance

A tool that helps teams decide how much AI output to send to human reviewers, starting with a simulator that compares review volume and errors across confidence thresholds.

Built for Cornell AI Strategy New Member Education.

## Current version
The hello page introduces the project. The simulator has not been built yet.

## How to use
1. Download or clone this repository.
2. Double-click `index.html` to open it in your browser.
3. Check that you see “Hello from Minseo” and the project description.
